# מדריך טיולים חי — Gemini 3.8 Live

לקוח מובייל לשיחה קולית בזמן אמת עם `gemini-3.8-live`, כולל וידאו מהמצלמה האחורית.

## איך זה בנוי

שתי דרכים להנפיק טוקן. מפתח ה-API אף פעם לא מגיע לטלפון.

**קישור קבוע (Vercel)** — הדרך המומלצת. אין QR, אין סקריפט להריץ:

```
iPhone  →  Vercel  →  /api/token מנפיק טוקן חד-פעמי  →  WebSocket ישיר לגוגל
                      (המפתח יושב כאן, במשתני הסביבה)
```

פותחים את הקישור, לוחצים "התחל", והדף מנפיק לעצמו טוקן טרי בכל שיחה.
הקישור נושא קוד כניסה ב-`#p=`, נשמר בטלפון בפעם הראשונה, ולכן אפשר להוסיף
למסך הבית ולשכוח ממנו.

**QR מהמחשב** — אם אתה מעדיף לא להחזיק את המפתח בענן:

```
המחשב שלך  →  mint_qr.py מנפיק טוקן  →  QR  →  סריקה מהאייפון
```

הדף תומך בשתי הדרכים: טוקן ב-`#t=` גובר, ובלעדיו הדף פונה ל-`/api/token`.

## פריסה ל-Vercel

1. חבר את הריפו לפרויקט ב-Vercel (בלי build command — זה אתר סטטי עם פונקציה אחת)
2. הגדר משתני סביבה:
   | משתנה | תפקיד |
   |---|---|
   | `GEMINI_API_KEY` | המפתח מ-https://aistudio.google.com/apikey |
   | `APP_PASSCODE` | קוד כניסה. מי שאין לו אותו לא יכול להנפיק טוקן |
   | `LIVE_MODEL` | אופציונלי, ברירת מחדל `gemini-3.8-live` |
   | `LIVE_VOICE` | אופציונלי, ברירת מחדל `Charon` |
3. הקישור לטלפון: `https://<הפרויקט>.vercel.app/#p=<APP_PASSCODE>`

## שימוש עם QR

1. הדבק את המפתח בקובץ `.env` (מ-https://aistudio.google.com/apikey)
2. הגדר `TRAVEL_LIVE_URL` לכתובת הדף
3. הרץ `python mint_qr.py`, סרוק מהטלפון, אשר מיקרופון, דבר

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | ממשק |
| `app.js` | לקוח Live API — אודיו, מצלמה, WebSocket, הנפקת טוקן |
| `pcm-worklet.js` | דגימת מיקרופון. חייב להיות קובץ נפרד — iOS חוסם worklet מ-blob URL |
| `api/token.js` | מנפיק טוקן בצד השרת. כל תצורת השיחה נקבעת כאן |
| `mint_qr.py` | הנפקה מקומית + QR, לזרימה בלי שרת |
