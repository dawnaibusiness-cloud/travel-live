# מדריך טיולים חי — Gemini 3.8 Live

לקוח מובייל לשיחה קולית בזמן אמת עם `gemini-3.8-live`, כולל וידאו מהמצלמה האחורית.

## איך זה בנוי

```
המחשב שלך          →  mint_qr.py מנפיק טוקן זמני  →  QR
                                                      ↓ סריקה
iPhone  →  GitHub Pages (דף סטטי)  →  WebSocket ישיר לגוגל
```

מפתח ה-API נשאר ב-`.env` במחשב. הדף הציבורי לא מכיל שום סוד —
הוא מקבל טוקן חד-פעמי שתקף 30 דקות ונעול למודל אחד.

## שימוש

1. הדבק את המפתח בקובץ `.env` (מ-https://aistudio.google.com/apikey)
2. הרץ `python mint_qr.py`
3. סרוק את ה-QR מהטלפון, אשר מיקרופון, דבר

לשיחה נוספת — הרץ שוב. הטוקן חד-פעמי.

## קבצים

| קובץ | תפקיד |
|---|---|
| `index.html` | ממשק |
| `app.js` | לקוח Live API — אודיו, מצלמה, WebSocket |
| `pcm-worklet.js` | דגימת מיקרופון. חייב להיות קובץ נפרד — iOS חוסם worklet מ-blob URL |
| `mint_qr.py` | מנפיק טוקן ומייצר QR |
| `vercel-alt/` | גרסת שרת חלופית, אם תעדיף להחזיק את המפתח בענן |
